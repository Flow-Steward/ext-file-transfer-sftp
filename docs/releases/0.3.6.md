# File Transfer 0.3.6

Dependency update for the FTP, FTPS, SFTP, S3-compatible and Dropbox
extension. This release updates the official botocore base from 1.43.127 to
1.44.2, covering dependency update issues #30 and #34.

- Bundle `botocore 1.44.2+flowsteward.1` and `aiobotocore 3.10.0+flowsteward.2`
  with exact hashes and reproducible, source-bound compatibility recipes.
- Adapt aiobotocore's copied asynchronous retry conditions to botocore's new
  HTTP 429 throttling checker. Preserve the presigned POST conditions ownership
  fix and exact python-dateutil 4.0.0 peer pins.
- Verify installed runtime/manifest consistency and all active dependency
  requirements, alongside real S3 signing, protocol, transport and isolation
  controls. Public operations, explicit-key-only credential selection, endpoint
  pinning, read limits and single commit attempt remain unchanged.

The maintained fork identities, scope, primary sources, licensing and rebuild
procedure are documented in [AWS compatibility](../aws-compatibility.md) and
`dependency-sources.json`. These wheels are maintained Flow Steward builds,
not official upstream releases or a broader AWS compatibility claim.
